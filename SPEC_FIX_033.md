# v033

Windows has a native single-line text composer below Android video. IME converts inline in this field. Conversion Enter does not send; another Enter or Send queues the entire draft. Drafts remain if the queue is full; UTF-8 scalars are never split. Up to 240 UTF-16 units per send. Navigation keys outside the field still control Android. F11 works from the field. UVC has no input bar. Android v032 behavior is retained.

IME behavior and Android text editing require physical-device validation.
